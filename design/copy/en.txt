-- Campaign BI (Group Wave Enterprise) --
[image] A weekly performance chart with fictional campaigns and invented media buyers, standing in for the internal system.
[mockup words] Campaign performance · Monthly · Weekly · W · Revenue · Spend · By media buyer · campaigns
Problem: Finance waited 45 minutes to 2 hours for each RedTrack CSV.
What I built: I designed and built it end to end: n8n publishes RedTrack data to a RabbitMQ queue and parallel NestJS workers write it to PostgreSQL, so a failed record is retried and nothing is lost. A Next.js app shows monthly, weekly and per-media-buyer results.
Architecture:
  RedTrack → n8n
  n8n → RabbitMQ
  RabbitMQ → NestJS (workers, API)
  Next.js app (Google sign-in) → NestJS (workers, API)
  NestJS (workers, API) → PostgreSQL
Result: Data refreshes every hour, and Campaign BI now runs inside Sistema Wave.
Stack: Next.js, NestJS, PostgreSQL, RabbitMQ, n8n, RedTrack
Internal system, no public link

-- Hostly (IA Robots Solutions) --
[image] A robot schedule screen with a fictional campaign playlist, standing in for the real system.
[mockup words] Today · Campaign · Music · Welcome message · Lobby set A · Spring offer · Lunch menu · Lobby set B · Now playing · Campaign, 30 seconds · Up next · Morning light · Open doors · Quiet hour · Second floor · Late check-in

What I built: I wrote the specification and build the whole system with AI coding agents: the robot app, the panel, the API and the media worker. The app reaches RobotOS through its own layer, the RobotGateway, so it runs without the real robot and can move to AgentOS later.

  API (NestJS) → PostgreSQL
  API (NestJS) → Registered LED screen (ads)
  Media worker (FFmpeg) → S3 storage
Result: In use, streaming ads to the robot and to LED screens.
